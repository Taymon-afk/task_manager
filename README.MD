# Сервис управления задачами (Task Manager)

## Назначение
Приложение для организации работы над проектами: позволяет создавать проекты, ставить задачи, назначать исполнителей и отслеживать статус выполнения.

## Целевая аудитория
Команды разработчиков, менеджеры проектов, фрилансеры, желающие структурировать рабочие процессы.

## Предметная область
Управление проектами и задачами. Пользователь может быть участником нескольких проектов, в каждом проекте создаются задачи с дедлайнами, приоритетами и комментариями.

## Основные функции
1. Проверка возможности создания задачи в проекте (по статусу проекта, лимиту задач и роли пользователя).
2. Определение текстовой метки приоритета задачи (высокий / средний / низкий).
3. Формирование карточки задачи с исполнителем, приоритетом и дедлайном.
4. (Планируется) Просмотр всех задач, назначенных на конкретного пользователя.
5. (Планируется) Добавление комментария к задаче.

## Основные сущности
- **Пользователь** – имя, email, роль (администратор, участник).
- **Проект** – название, описание, дата начала/окончания, статус (активен, завершён).
- **Задача** – относится к проекту, название, описание, исполнитель, дедлайн, приоритет (низкий, средний, высокий), статус (новая, в работе, готова, закрыта).
- **Комментарий** – привязывается к задаче, текст, автор, время создания.

## Основные функции
1. Просмотр списка проектов с их статусами.
2. Создание новой задачи в выбранном проекте.
3. Изменение статуса задачи.
4. Добавление комментария к задаче.
5. Просмотр всех задач, назначенных на конкретного пользователя.

## План развития
На следующих этапах планируется:
- Разработка веб-приложения на Django с шаблонами.
- Подключение базы данных (PostgreSQL) для хранения сущностей.
- Реализация аутентификации и авторизации пользователей.
- Разработка REST API.
- Контейнеризация приложения с помощью Docker.
- Настройка CI/CD для автоматического тестирования и деплоя.
