# Сервис управления задачами

## Назначение

Консольное приложение для управления пользователями, проектами и задачами.

Приложение позволяет:

- просматривать и добавлять пользователей;
- просматривать и добавлять проекты;
- создавать задачи;
- назначать исполнителей;
- задавать приоритет и срок выполнения;
- отмечать задачи как выполненные;
- сохранять данные между запусками.

## Предметная область

Основные сущности приложения:

- пользователь;
- проект;
- задача.

Пользователь может создавать задачи при наличии соответствующих прав. Проект содержит коллекцию задач. Каждая задача связана с пользователем-исполнителем.

## Основные классы

### User

Атрибуты:

- `id` — идентификатор;
- `name` — имя;
- `role` — роль.

Методы:

- `can_create_tasks()` — проверка права создавать задачи;
- `__str__()` — строковое представление пользователя.

### Project

Атрибуты:

- `id` — идентификатор;
- `name` — название;
- `status` — статус;
- `max_tasks` — максимальное количество задач;
- `tasks` — коллекция объектов `Task`.

Методы:

- `current_tasks_count` — количество задач;
- `can_add_task()` — проверка возможности добавить задачу;
- `add_task()` — добавление задачи;
- `__str__()` — строковое представление проекта.

### Task

Атрибуты:

- `id` — идентификатор;
- `title` — название;
- `assignee` — объект пользователя-исполнителя;
- `priority` — приоритет;
- `deadline` — срок выполнения;
- `is_completed` — признак выполнения.

Методы:

- `get_priority_label()` — название приоритета;
- `complete()` — завершение задачи;
- `__str__()` — строковое представление задачи.

## Взаимодействие объектов

Объект `Project` содержит коллекцию объектов `Task`.

Объект `Task` содержит ссылку на объект `User`, являющийся исполнителем.

При добавлении задачи проверяются:

- активность проекта;
- лимит задач;
- права пользователя;
- уникальность идентификатора задачи.

## Хранение данных

Данные сохраняются в JSON-файлах:

- `data/users.json`;
- `data/projects.json`;
- `data/tasks.json`.

При загрузке JSON создаются объекты классов. Связи задач с проектами и пользователями восстанавливаются по идентификаторам.

## Установка

Создание виртуального окружения:

```powershell
python -m venv venv
```

Активация:

```powershell
venv\Scripts\Activate.ps1
```

Установка зависимостей:

```powershell
python -m pip install -r requirements.txt
```

## Запуск

```powershell
python main.py
```
